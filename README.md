# 小红书 MaiBot 插件（开发中）

本目录为开发验证版，请先在隔离 MaiBot 环境试用。尚未完成长期稳定性、完整依赖许可证和市场审核验证。

功能包括 WebUI 扫码登录、仅对白名单开放的私信网关、转发图文的文字和首图解析、兴趣驱动的定时浏览与摘要保存，以及根据配置素材自主规划图文发布。插件、浏览、发布默认禁用，私信白名单默认为空，回复概率默认 0。账号和用户均使用小红书稳定用户 ID；小红书号不是稳定用户 ID。

## 安装

需要 MaiBot 1.3.16 至 1.3.x 与 `maibot-plugin-sdk` 2.16.x。市场收录后可在 MaiBot WebUI 插件市场搜索并选择版本安装；正式收录前，可将 GitHub Release 的源码包解压到实例的 `plugins` 目录下的独立文件夹，确保该文件夹直接包含 `_manifest.json` 和 `plugin.py`，再按宿主的插件管理方式加载。依赖由宿主插件管理器处理，安装可能触发依赖同步与插件运行进程重启，请选择合适时间操作。

安装后先在插件设置中检查默认值，再打开“小红书登录”页面登录；按需添加稳定用户 ID 白名单和配置浏览、发布。不要将会话文件、登录二维码或 Cookie 发给他人。

只查询白名单会话，先核验发送方、接收方及私聊范围再解析正文，出站时再次检查目标。回复概率控制送往小红书的回复；白名单消息仍会进入麦麦上下文，麦麦也可以自行决定不回复。消息连续到达时，回复开关按该会话最新一条接收消息的抽样结果判断，不保证逐条精确统计。

自主浏览按用户兴趣搜索公开笔记，关键词搜索不附带账号 Cookie，搜索为空时使用账号推荐流，调用 Host 模型生成摘要；每个账号最多保存 500 条，可检索最近 30 天的内容，写入新摘要时清理过期记录。麦麦可通过工具查询这些摘要。这是可检索的笔记记忆，不会训练或修改模型。模型会被要求将第三方内容当作数据处理，但无法保证完全抵御恶意内容。转发笔记目前只处理文字与第一张图片；是否理解图片取决于麦麦所用模型的视觉能力。

## 扫码登录

插件启用后，在插件扩展页面打开“小红书登录”，点击“扫码登录”，使用小红书 App 扫描并确认。二维码和进行中的登录状态只保存在内存；成功验证后会保存会话，并按配置恢复白名单网关。二维码过期可重新开始；取消或登录失败不会覆盖先前保存的会话。

如果平台返回 461/471，插件停止请求并提示人工处理，不自动识别、绕过或重复挑战。当前备用方案是在本机浏览器按平台要求完成登录并通过下方登录助手导入会话。助手导入后可点击“使用已保存会话”恢复网关；该备用流程的通用跨机器用法仍需验收。

## 配置

在插件设置中开启 `plugin.enabled`，并根据需要设置：

- `dm.allowed_users`：允许通信的稳定用户 ID 列表；`dm.reply_probability` 为 0 到 1；`dm.poll_seconds` 为轮询间隔。
- `browse.enabled`：启用浏览；`browse.interests` 填写感兴趣的主题词；`browse.interval_seconds` 控制间隔，最少 300 秒；`browse.notes_per_cycle` 控制每次最多保存几篇。兴趣为空时不会浏览。多个兴趣按轮次依次搜索；搜索为空时使用推荐流。
- `browse.timezone` 默认 `Asia/Shanghai`；`browse.time_windows` 可以填多个 `HH:MM-HH:MM` 时间段，留空为全天；`browse.start_date` 与 `browse.end_date` 可限制日期，留空不限制。例如只在 2026-10-30 的 09:00 至 11:00 浏览：两个日期都设为 `2026-10-30`，时段设为 `09:00-11:00`。跨午夜时段归属于开始的日期。此限制只影响主动浏览，私信和发布不受影响。
- `browse.daily_token_limit` 控制每天浏览用量，默认 `0` 表示不限制。用量按模型返回的统计累加，在每次模型请求之前检查，所以最后一次调用可能超出上限；若请求未返回用量，设置了上限时会停止当天继续浏览。登录页面显示当日浏览与发布规划用量，未包含私信对话、转发图片理解和无法取得用量的请求。
- `publish.enabled`：允许自动规划和发布，默认关闭；`publish.interval_seconds` 控制最短发布间隔。`publish.instructions` 可填写内容风格和素材说明。
- `publish.image_mode` 默认为 `upload`：在插件数据目录的 `publish-images` 放入有权使用的图片，并在 `publish.image_files` 填写 1 至 9 个文件名。设为 `text_card` 时使用小红书原生“文字配图”生成标题配图；`publish.text_card_style` 可选择样式序号 0 至 9。原生配图返回的图片仅临时保存用于发布。
- `publish.private` 默认 `true`，发布为仅自己可见。设为 `false` 后会尝试公开发布，请先在独立账号验证自动规划的内容符合预期。

`browse.model_task` 和 `publish.model_task` 可指定 MaiBot 中已配置的模型任务，默认 `utils`；请确保对应任务可用，并能遵循结构化输出要求。使用视觉模型接收转发图片的设置由麦麦自身决定。

一次隔离实测中，关键词搜索后由 `utils` 模型选择并概括一篇笔记，两次调用合计 1,033 Token（输入 306、输出 727）；另一次转发首图的视觉调用为 2,535 Token（输入 1,370、输出 1,165），一次文字卡片发布规划为 629 Token（输入 136、输出 493）。这只是不同任务的单次样本，实际用量取决于模型、图片和笔记内容。纯接口读取通常不产生模型 Token。私信对话、视觉理解、失败重试和发布规划需要另计；费用请按模型服务商实际账单计算，配置中的零价格不代表免费。

模型决定不发布、生成内容格式无效或素材缺失时会跳过。提交后如结果不明确，自动发布会暂停，页面可显示状态。请先在小红书确认是否已经发出，再使用页面上的按钮解除暂停；否则可能重复发布。

## 已知限制

- 历史消息按边界重叠分页并去重，单次最多读取 10 页。超过上限时停止处理并提示，不会声称已完整读取。跨重启和异常情况下的真实消息补偿仍需长期验证。
- 投递 Host 前记录发送中状态，Host 接收后确认；中途崩溃或 Host 返回拒绝时结果可能不确定，为避免重复不自动重投，因此仍可能需要人工检查，不能承诺恰好一次投递。
- 插件停用或取消白名单时会重置相应接收起点；停用期间的消息不会补发。没有对账号使用长期运行和多用户压力测试。
- 临时文件和凭据应保存在 MaiBot 提供的插件数据目录内，不能提交仓库；该目录需限制权限。浏览器辅助导入凭据须使用安全连接，不能将 Cookie 发到聊天中。

## 依赖与协议

使用独立依赖 `xhshow`、`curl-cffi`、`pycryptodome`；网关和模型调用只使用公开 `maibot_sdk`。私信协议字段按实验中观察的接口和 protobuf 格式独立实现。可行性实验使用过 Spider_XHS，但其源码未包含在本插件中；发布接口的公开第三方资料包括 [ReaJason/xhs](https://github.com/ReaJason/xhs) 和 [xhshow](https://github.com/Cloxl/xhshow)。最终分发前仍需完成所有依赖及协议资料的许可证审查。

## 实验性浏览器登录助手

运行环境为用户自己的电脑，需要 Node.js、`tools/package.json` 所列 Playwright、已安装的 Chrome 和 SSH 客户端。可在本机的 `tools` 目录执行 `npm install` 安装助手依赖，不需要在服务器安装浏览器。服务器上插件目录需包含 `tools/import_session.py` 和已安装的 Python 依赖。调用方式如下，所有路径和主机均由用户自行替换：

```text
node tools/browser_login.cjs --host 用户名@服务器 --identity 本机私钥路径 --known-hosts 本机已验证的known_hosts路径 --plugin-dir /服务器/插件目录 --data-dir /服务器/插件数据目录 --python /服务器/Python路径 --browser 本机Chrome路径
```

可选 `--port`，默认 22；远端路径目前仅支持 ASCII 字母、数字、点、斜线、下划线和短横线。助手启动独立浏览器，登录并手动完成验证后，在启动助手的终端按回车。登录状态仅通过启用严格主机密钥检查的 SSH stdin 传给服务器，验证账号后存入 `<data-dir>/auth/session.json`；不会写入命令行或终端输出。用户应事先自行确认 SSH 主机密钥。脚本不会启用插件或重启 MaiBot。

执行 `python -m unittest discover -s tests -v` 运行本地测试。发布前需继续核对许可证与依赖兼容性、完善尚未完成的真实环境验收，并按[官方文档](https://docs.mai-mai.org/plugin/submission)完成市场发布流程。
