# 麦麦小红书

让麦麦浏览小红书、阅读白名单用户的私信和转发笔记，并根据配置自主规划图文发布。

目前是预览版，使用非官方接口；小红书的接口或登录验证发生变化时，部分功能可能暂时不可用。

## 功能

- **私信**：可选择只处理白名单用户，或处理所有人的单聊私信；可设置回复概率，麦麦也可以决定不回复。
- **转发笔记**：读取笔记文字和第一张图片；图片理解需要麦麦配置视觉模型。
- **兴趣浏览**：填写感兴趣的主题，设置浏览日期、时段和频率；在插件扩展的“小红书浏览记录”查看读过的笔记和摘要。
- **图文发布**：根据你的创作要求和浏览摘要规划内容，可使用自备图片或小红书文字卡片。默认发布为仅自己可见。

## 安装与登录

需要 MaiBot 1.3.16 至 1.3.x、`maibot-plugin-sdk` 2.16.x。市场收录后，可在麦麦 WebUI 的插件市场搜索并安装本插件。

也可以下载 [GitHub 预发布版本](https://github.com/neal240/maibot-xiaohongshu/releases)，将源码包解压到 MaiBot 实例的 `plugins` 目录下的独立文件夹，确保文件夹内直接包含 `_manifest.json` 和 `plugin.py`。按麦麦的插件管理方式加载插件；安装依赖时，现有插件可能短暂重载。

安装后，在插件设置中启用插件，打开“小红书登录”页面，使用小红书 App 扫码并确认。若平台要求验证，请按页面提示自行完成；如提示 461 或 471，插件会停止请求，等待人工处理。

登录会话相当于账号凭证，请勿分享二维码、Cookie 或会话文件。

## 常用设置

插件、主动浏览和自动发布默认关闭，私信白名单默认空，回复概率默认 0。启用需要的功能后，可在插件设置中调整：

- `dm.mode`：默认为 `whitelist`，只处理白名单；改为 `all` 后处理所有人的单聊私信，不需要填写用户 ID。群聊不处理。
- `dm.allowed_users`：允许处理私信的用户 ID 列表。获取方法见下文；主页显示的小红书号不能直接填入。
- `dm.reply_probability`：回复概率，范围 0～1；例如 `0.5` 表示约一半消息允许回复，`1` 表示全部允许。允许回复后仍由麦麦自行决定是否回应。
- `browse.interests`：参考兴趣和搜索词。启用 `browse.enabled` 后，麦麦先从首页推荐里挑选感兴趣的笔记；没有合适的内容时，再随机选择一个词搜索。留空时只看首页推荐。
- `browse.interval_seconds` 和 `browse.notes_per_cycle`：浏览间隔及每次保存的笔记数量。
- `browse.timezone`、`browse.time_windows`、`browse.start_date` 和 `browse.end_date`：设置主动浏览的时区、时段和日期。例如只在 2026 年 10 月 30 日的 09:00–11:00 浏览，可将起止日期都设为 `2026-10-30`，时段设为 `09:00-11:00`。时段留空表示全天。
- `browse.daily_token_limit`：主动浏览每日 Token 上限，`0` 表示不限制；最后一次请求可能略超上限。
- `publish.instructions`：填写创作要求；启用 `publish.enabled` 后允许麦麦自行规划发布。`publish.interval_seconds` 设置最短发布间隔。
- `publish.image_mode`：选择 `upload` 使用插件数据目录 `publish-images` 中的自备图片，并在 `publish.image_files` 填写文件名；选择 `text_card` 使用小红书文字卡片，`publish.text_card_style` 可选择样式。
- `publish.private`：默认为 `true`，图文仅自己可见；改为 `false` 后可尝试公开发布。

浏览摘要属于插件保存的可检索记录，不会训练或修改模型。浏览和创作调用模型会产生 Token 消耗；登录页面显示可统计的浏览和发布规划用量，私信对话及图片理解的用量需要另行查看。

浏览记录保存在本机，最多保留 30 天、500 条。新版会记录麦麦实际打开并尝试总结的笔记，包括接口返回的标题、正文和摘要；较早版本只保存了摘要，无法还原原文。

## 怎么找到白名单用户 ID

白名单使用的是用户主页地址中的内部用户 ID，不是个人资料中显示的“小红书号”。目前插件要求 ID 为 24 位，由数字和小写字母 `a`–`f` 组成。

1. 在小红书打开要加入白名单的人的个人主页，点击分享并复制主页链接。
2. 用电脑浏览器打开分享链接，进入该用户的网页版主页。如果分享的是 `xhslink.cn` 或 `xhslink.com` 短链接，需要先打开它，不能直接把短链接填进白名单。
3. 在浏览器地址栏找到 `/user/profile/`，复制它后面的 24 位字符，到问号 `?` 或斜杠 `/` 前为止。例如：

   `https://www.xiaohongshu.com/user/profile/0123456789abcdef01234567?xsec_token=...`

   这个示例中应填写 `0123456789abcdef01234567`。这是演示用 ID，不代表真实用户。
4. 在 `dm.allowed_users` 中逐个添加这些 ID。请核对主页确实属于想允许的用户；如分享链接未能打开网页版主页，可在小红书网页版搜索该用户并进入主页后查看地址。

## 使用提示

- 小红书登录状态可能过期或遇到风控，需要时请重新登录并按平台提示验证。
- 转发笔记目前只读取第一张图片；视觉理解效果取决于配置的模型。
- 若图文提交结果不明确，插件会暂停自动发布。请先在小红书确认是否发布成功，再在插件页面解除暂停，避免重复发布。
- 白名单消息会进入麦麦上下文；连续收到消息时，回复开关按该会话最新消息的抽样结果判断。
- 切换私信模式后，只处理该模式开启后到达的消息；所有人模式一次最多检查 200 个会话，超过上限时会停止并提示。
- 预览版尚未完成长期运行和多用户压力验证；有关依赖许可证的记录见 [THIRD_PARTY.md](THIRD_PARTY.md)。

问题和建议请提交至 [GitHub Issues](https://github.com/neal240/maibot-xiaohongshu/issues)。
